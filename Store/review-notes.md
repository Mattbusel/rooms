# App Review notes

---

No account, login or network connection is required.

HOW TO USE: The Inventory tab shows your rooms. Tap a room, then the terracotta plus button to add an item: take a photo or pick one from the library, type a name and a replacement value, save. Tap the home name at the top to enter your policy details (contents cover, deductible, category caps). The Coverage tab checks your totals against those limits, Value shows depreciated worth and what is missing for a claim, and Report makes a PDF and a CSV to share.

PRIVACY: no data is collected. Everything is stored in the app's Documents folder on the device (a JSON file plus JPEG photos). The camera and photo library are used only to attach photos to the user's own inventory, and only when the user taps Camera or Library. No network requests are made.

2. PURPOSE AND TARGET AUDIENCE
Rooms is a personal home inventory for insurance: a room-by-room record of belongings with photos, serial numbers and replacement values, a coverage check against the user's own policy limits, and a printable claim report. General audience of homeowners and renters; rated 4+.

3. SETUP AND ACCESS
No setup, login or credentials. A new install starts with three empty rooms; add a room or tap the plus to add an item. Policy details are optional and typed in by the user.

4. EXTERNAL SERVICES, TOOLS AND PLATFORMS
None. No network requests, analytics, advertising or third-party frameworks. Built with SwiftUI, Foundation, PhotosUI (photo picker) and UIKit (camera capture, PDF rendering).

5. REGIONAL DIFFERENCES
None. The currency symbol is a free-text setting.

6. REGULATED INDUSTRY / PROTECTED MATERIAL
Not applicable. The app does not sell or broker insurance; it only records what the user owns and compares it with limits the user typed in. All art, text and code are my own work.
